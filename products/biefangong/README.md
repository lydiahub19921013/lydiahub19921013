# Lydia · 别返工

**客户一句“顺便改下”，可能就是一轮免费返工。**

「别返工」面向在微信、飞书等聊天工具里接需求的独立开发者、设计师、代运营、视频制作者、顾问和小型外包团队。

它不是一份需要用户自己研究的提问方法，而是持续保存每个项目当前已经确认的约定。客户再发新消息时，把整段贴进来，它会告诉你：

- 后来又加了哪些工作；
- 原来已经说定的内容哪里变了；
- 哪些要求还没有说清楚；
- 交付时间是否被要求保持不变；
- 应该怎样回一条边界清楚、又不跟客户吵架的确认消息。

## 三步完成一次核对

1. 输入项目名，保存双方已经说定的内容。
2. 客户发来新需求或修改时，整段复制过来。
3. 查看新增、变化和待确认问题，再决定是否把确认草稿放回聊天框。

回复不会自动发送，项目约定也不会在用户确认前更新。

## 它和「说人话」不是一回事

- [说人话](https://github.com/lydiahub19921013/shuorenhua)解决的是：对方说了一大段，到底想让我做什么，我该怎么回。
- 「别返工」解决的是：这个项目原来已经说定什么，这次到底又多了什么，时间和费用是否需要重新确认。

两款应用使用不同的名称、快捷键、本机数据和应用身份，可以同时安装。

## 当前状态

- 版本：v0.1.0 内测候选版。
- 平台：Apple Silicon Mac，macOS 13 及以上。
- 本机核对：移动端、导出、登录、支付、权限、报表、搜索和提醒等常见变更。
- 复杂消息：可在开发设置中连接 AI；所有结果仍需用户自己确认。
- 发布边界：当前没有公开下载，不冒充已经完成大规模用户验证。
